# 🏦 Bank Loan Analytics – Excel Dashboard

## 📌 Project Overview

Bank Loan Analytics is a data analysis and business intelligence project developed using Microsoft Excel. This project analyzes banking and loan-related data to understand loan funding, collections, interest, customer distribution, branch performance, and credit risk indicators.

The dashboard transforms raw banking data into meaningful insights through visualizations and supporting analysis sheets, helping users understand loan portfolio performance and make data-driven decisions.

## 🎯 Project Objectives

- Analyze total loan amount funded and total number of loans.
- Evaluate loan collections and interest performance.
- Compare loan performance across different branches and states.
- Understand loan distribution across product groups and customer categories.
- Analyze loan disbursement trends over time.
- Examine loan grades and loan maturity periods.
- Monitor delinquent clients and default loan indicators.
- Identify patterns in the loan portfolio to support better business decisions.

## 📈 Dashboard Features & Visualizations

### 1. Branch-wise Loan Analysis
Analyzes loan funding and payment performance across different branches.

### 2. State-wise Loan Distribution
Compares loan amounts and loan counts across different states.

### 3. Religion-wise Loan Distribution
Examines the distribution of loans across the categories available in the dataset.

### 4. Product Group Analysis
Analyzes loan distribution and funding across different product groups.

### 5. Loan Disbursement Trend
Visualizes loan disbursement patterns across different years and quarters.

### 6. Loan Grade Analysis
Examines loan amounts across different loan grades.

### 7. Age Group-wise Loan Analysis
Analyzes loan distribution across different customer age groups.

### 8. Loan Maturity Analysis
Compares loans based on 36-month and 60-month maturity periods.

### 9. Delinquency & Default Analysis
Evaluates delinquent and default-related loan indicators to understand portfolio risk.
